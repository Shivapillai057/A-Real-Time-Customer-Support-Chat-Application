## Project Scope
SupportChat is a beginner-friendly full-stack web application that enables real-time communication between customers and support agents. Customers can create support tickets, select a query category, and chat instantly without refreshing the page. Agents can view all active conversations in a centralized dashboard, join any chat with a single click, and provide immediate assistance. All messages are securely stored in a database, allowing complete conversation history for future reference. The project demonstrates full-stack development concepts, including real-time messaging, database integration, responsive user interfaces, and efficient customer support management.
